# Sanket Khatri — Senior iOS Developer

Personal portfolio: https://sanketk2020.github.io/

A static site (plain HTML, CSS and JavaScript, no build step on the server). Eight pages: Home, About,
Skills, Experience, Projects, Certificates, Get in touch and Cover letter, with light and dark themes.

This folder is generated. To change the site, edit the Lilac sources in `portfolio-designs/_src`, then run:

```
python3 _src/build.py 53 && python3 _src/export_lilac.py
```
